## 0. 结论先行（TL;DR）

1. **页面流**：启动 Splash → 主菜单 →（难度选择=底部抽屉）→ 对局 Game → 结算 Result（底部弹层）→ 成就墙 / 每日榜。全部竖屏，顶部仅放低频导航（难度/设置/每日），高频操作（笑脸/雷数/计时/撤销/模式）**全部底部化**（R5）。
2. **手势阈值已钉死且跨文档一致**：点按=翻开；长按 **350ms**（环形进度+轻震动）=循环标记；双击 **300ms**（仅已翻开数字格）=连开 chord；笑脸=重开；模式按钮=挖掘/标记切换（与长按并存不互斥）。冲突仲裁以「350ms + 12dp 位移阈值」区分长按/点按，以「300ms 同格」区分双击/点按。
3. **标记双方案并存、设置单选默认**：`default_mark_mode ∈ {longpress, button}`，**默认 longpress**（贴近桌面右键直觉）；两者能力始终都在，可叠加。
4. **首玩引导 3 步**闭环 Phase 2 认知过载⚠：教点按 / 长按 / chord，触发于首启未引导，可跳过，完成写 `onboarded=true`。
5. **无障碍三开关**：色盲辅助、减少动态、大字体（显示缩放），均在设置页入口，引用美术圣经 §8.2/§8.4；触控热区恒 ≥44dp。
6. **每日挑战已定方案**：自由首击 + `DAILY_CONFIG = {16×16/40}`（中级），复用全部核心逻辑；每日榜展示今日最佳与历史。
7. **待确认 1 项**（T1）：`toolbar_mode` 默认建议改 **true**（让模式按钮默认可见，落实「两者都提供」），与系统设计 GDD §2.5 占位值 false 不一致，需主理人/工程确认（见 §7）。

### 2.3 棋盘区 Board Area（中部 flex）

- **容器**：`ScrollView`（双轴滚动）包裹单 `BoardWidget`（ADR-02 单 Canvas/单 Widget）；`Scatter` 或 `BoardWidget` 内置 `scale` 属性承接 **pinch-zoom**。
- **`cell_dp` 计算**（美术圣经 §4.1 / HUD 系统算法）：
  ```
  avail   = min(viewport_w, viewport_h − TopNav(48) − BottomHUD(104) − margins(16))
  cell_dp = clamp(round(avail / max(rows, cols)), CELL_MIN=30, CELL_MAX=56)
  if cell_dp < MIN_TAP_DP(44):      # 大棋盘(>16列)必触发
      启用 ScrollView 双轴滚动 + pinch-zoom 放大到 ~48dp（不压缩热区，R2）
  ```
- **接入点**：`board_widget.py` 暴露 `set_scale(s)`、`scroll_to(r,c)`；手势层把双指捏合映射为 `set_scale`，单指拖动映射为 ScrollView 滚动。
- **零间隙**：格与格紧贴（bevel 分界），仅屏边 8–16dp 留白（美术圣经 §3/§6）。

## 3. 触屏交互规格（细化 GDD §2.2）

### 3.1 常量（与美术圣经 / GDD / 架构 三处一致）

| 常量 | 值 | 定义处 |
|------|----|--------|
| `LONG_PRESS_MS` | **350** | 美术圣经附录 A / GDD §2.2 / 架构 §2.2 |
| `DOUBLE_TAP_MS` | **300** | 同上 |
| `TAP_SLOP_DP` | **12** | 本规格新增：位移容忍，超此视为拖动而非点按 |
| `UNDO_DEPTH` | **1** | GDD §2.2（可配置 ≤5） |
| `TIMER_CAP` | **999** | 核心不变 |
| `MIN_TAP_DP` | **44** | 美术圣经 §4.1 |
| haptic | 轻震动（长按触发 10–15ms；踩雷/胜利更重） | 美术圣经 §7/§8.3 |

### 3.2 手势 → 动作 映射（权威表）

| 手势 | 触发条件 | 动作 | 备注 |
|------|----------|------|------|
| 单指点按 tap | down→up < 350ms 且位移 < 12dp | `reveal(r,c)` | 若 `flagged`→忽略；若 `marked`→先清 `?` 再 reveal |
| 长按 long-press | 单指静止按住 ≥ 350ms | `cycle_mark(r,c)`（无→旗→?→无） | 环形进度 + 轻震动；触发即消费该次 down，不再发 tap |
| 双击 chord | 同格 ≤300ms 内第二击，且 `revealed and number>0` | `chord(r,c)` | 单点已翻开数字格 = noop（防误触，R1 适配） |
| 点按笑脸 | tap 笑脸控件 | `game.new_game()` | 同难度重开 |
| 模式按钮切换 | tap 模式控件 | `tool_mode ∈ {dig, mark}` 翻转 | mark 模式下 tap=cycle_mark；**长按仍恒为 cycle_mark**（GDD 边界 8） |
| 撤销 | tap 撤销控件 | `undo()` | 还原棋盘快照，不动计时 |

### 3.3 手势时序与状态机（TouchDispatcher）

```
on_touch_down(cell, t0):
    long_timer = Clock.schedule_once(_fire_longpress, 0.350)   # 起环形进度 + 预震动
    last_down_cell = cell; last_down_t = t0; moved = False

on_touch_move(d):
    if dist(down, d) > TAP_SLOP_DP: moved = True
    if moved: 取消 long_timer（转滚动/pan，不标记不翻开）

_fire_longpress():
    if still_down and not moved:
        cycle_mark(last_down_cell)          # 消费 down，置 long_fired=True
        haptic(light)

on_touch_up(t1):
    cancel(long_timer)
    dt = t1 - last_down_t
    if long_fired: return                    # 长按已处理，结束
    if moved: return                          # 拖动，交给 ScrollView
    # 判定 点按 / 双击
    if (last_tap_cell==cell and (t1-last_tap_t) <= 0.300
            and board.is_revealed(cell) and board.number_at(cell) > 0):
        chord(cell); last_tap_cell=None       # 双击 chord
    else:
        handle_tap(cell)                      # reveal / 或 mark 模式 cycle_mark
        last_tap_cell=cell; last_tap_t=t1
```

### 3.4 冲突仲裁矩阵（Conflict Arbitration）

| 冲突对 | 仲裁规则 |
|--------|----------|
| **长按 vs 点按** | 350ms 阈值 + 12dp 位移阈值：<350ms 抬起 **或** 位移 >12dp = 点按；≥350ms 静止按住 = 长按。长按一旦触发 `long_fired`，消费该次 down，不补发 tap（杜绝「想翻开却插旗」，GDD §2.2 边界 1）。 |
| **双击 vs 点按** | 首击记录 `(cell, t)`；第二击若**同格且 ≤300ms 且 revealed&number>0** → chord；否则该次按常规 tap 处理。因对已翻开数字格 `reveal` 为 noop（GDD 边界 3/6），双击第一击不会误翻普通格，连开安全。 |
| **长按 vs 双击** | 天然互斥：长按作用于未翻开格循环标记；双击仅对已翻开数字格触发 chord。标记态下该格 `not revealed`，chord 条件不满足；故同格先后手势不打架。 |
| **模式按钮 vs 长按** | 并存不互斥（GDD §2.2 边界 8）：`mark` 模式下 tap=标记，但**任意模式**下长按仍 = `cycle_mark`。方案 A（长按）永远可用，方案 B（按钮）为叠加增强。 |
| **点按 vs 滚动/缩放** | 棋盘区：单指位移 >12dp = 滚动(pan)；双指 = pinch-zoom；单指静止轻点(<350ms & <12dp) = tap。长按环形进度**仅单指静止按住**时显示，拖动/缩放下不显示。 |
| **插入旗格上的长按** | 继续循环（旗→?→无），与桌面右键一致（GDD §2.2 边界 2）。 |
| **game_over 后** | 撤销禁用（胜/负不可撤销，防成就被篡改，GDD §2.2 边界 5）；重开仅笑脸。 |

### 3.5 设置页「标记默认方式」单选（持久化）

- **设置项**：`default_mark_mode ∈ {longpress, button}`
- **默认值**：`"longpress"`（贴近桌面右键直觉，新手零学习；`button` 供偏好工具栏用户）。
- **`toolbar_mode`**：是否默认显示模式切换按钮。**本规格建议默认 `true`**（落实用户拍板「两者都提供」，提升模式按钮可发现性）；与 GDD §2.5 JSON 占位 `false` 不一致 → 见 §7 待确认 T1。
- **持久化**：写入 `settings.json`（`core/storage`）；启动 `interaction.py` 读 `default_mark_mode` 初始化 `tool_mode`：
  - `longpress`（默认）→ 初始 `tool_mode=dig`，标记靠长按；
  - `button` → 初始 `tool_mode` 依 `toolbar_mode` 决定，标记优先靠按钮切换。
- 两者**始终都能用**（长按恒在 + 按钮可显），设置只定「默认主用哪种」，不剥夺另一种。

## 4. 首玩引导（3 步 · 闭环 Phase 2 认知过载⚠）

### 4.1 触发时机
- **首启引导**：`settings.json` 无 `onboarded` 字段（或 `false`）→ 首次进入对局 S3 前弹引导层。
- **重看**：设置 S7 / 主菜单「玩法?」按钮可重新触发（不强制）。
- **跳过**：每步右上「跳过 ✕」；引导层顶部进度「1/3」。

### 4.2 三步流程（Coach Marks）

| 步 | 高亮对象 | 文案（示意） | 用户动作 → 反馈 |
|----|----------|--------------|----------------|
| 1 | 一个**未翻开**安全格（教学局或真实首局首击） | 「轻点格子，揭开它」 | 用户 tap → `reveal` 演示（首次点按即首击安全，无雷） |
| 2 | 同一格或相邻未翻开格 | 「按住约 0.3 秒，插旗 / 循环标记」 | 用户长按 ≥350ms → `cycle_mark` 插旗 + 环形进度 + 轻震动演示 |
| 3 | 一个**已翻开数字格**（教学局预置，或提示真实对局中） | 「快速双击数字格，连开周围」 | 用户双击 ≤300ms → `chord` 涟漪演示 |

> 教学局：为避免破坏真实数据，步骤 1–2 可在**预置小盘（如 9×9/8）**上演示；步骤 3 需已翻开数字格，教学局预置一处已翻数字 + 邻格安全以便 chord 可见效。引导结束不计入 best/成就。

### 4.3 闭环说明
Phase 2 设计评审四忌⚠项「认知过载」的根因是标记双方案并存；本引导**只教长按 + 双击 + 笑脸**（不提前抛模式按钮概念），配合 §3.5 单选默认，使新手首局只需理解 1 种标记方式，认知负荷降至最低，彻底闭环该⚠。

## 5. 结算 / 成就墙 / 每日榜 界面流程

### 5.1 结算 Result（底部 Modal Sheet，S4）

| 状态 | 视觉（引用美术圣经 §7） | 弹层内容 |
|------|--------------------------|----------|
| **胜利 win** | 笑脸 cool + 全盘红旗亮起；底部弹层 | 难度名 · 用时（封顶 999）· 「新纪录!」徽标（if `best` 刷新）· 解锁成就 toast；按钮：再来一局 / 选难度 / 看成就 |
| **失败 lose** | 笑脸 dead + 触发格红闪 + 抖屏（reduce_motion 关时）+ 全盘揭示雷 + 错误旗红叉 | 失败 + 用时；按钮：再来一局 / 选难度 / 看成就 |

- 弹层**不占满屏**，背后棋盘可见；`game_over` 后撤销禁用（§3.4）。
- 胜利写 `best[level]=min` 与成就结算（事件驱动，幂等）。

### 5.2 成就墙 Achievements（S5）

- 列表展示 `ACHIEVEMENTS`（GDD §2.4 九枚）：初次通关 / 入门通关 / 专家征服 / 地狱征服 / 闪电思维(≤60s) / 连开大师(chord≥20) / 零误旗 / 每日首胜 / 旗帜如林(插旗≥50)。
- 每枚：Canvas 绘徽章（锁定=灰；解锁=亮）+ 名称 + 描述 +（累计型）进度条。
- 新解锁：对局胜/负结算时 toast 高亮 + 墙内亮起。
- 入口：主菜单 / 结算「成就」。

### 5.3 每日挑战入口与每日榜（S6）

- **入口**：主菜单「每日挑战」/ 顶部「每日 ☀」。
- **开局**：`game.start_daily()` → `DAILY_CONFIG={16×16/40}`（**自由首击**，用户拍板覆盖 system-design 固定中心方案，架构 §3.3）+ 种子 `random.Random(int(YYYYMMDD))`。
- **每日榜页**：今日日期 · 今日最佳用时（`daily_best`，胜利才写，取 `min`）· 是否完成标记 · 近 N 日历史最佳列表。
- **确定性**：同日期 + 同首击格 → 同盘；不同首击格仅 3×3 禁区微差（已确认「近似同盘」，不破坏可比性）。时区取用户本地日期（在线期再统一 canonical，标注）。

## 6. 无障碍 UX（Accessibility）

| 开关 | 入口 | 行为 | 引用 |
|------|------|------|------|
| **色盲辅助** `colorblind` | 设置 S7 | 开 → 数字切 Okabe-Ito 安全色板 + 每数字叠**形状/底点冗余**（数字下方小方块数=该数字）；地雷/红旗本就形状编码，天然安全 | 美术圣经 §8.2 |
| **减少动态** `reduce_motion` | 设置 S7 | 开 → 关抖屏/缩放/级联，仅状态即时切换；惠及前庭敏感用户 | 美术圣经 §8.4 / HUD 边界 4 |
| **大字体 / 显示缩放** | 设置 S7 | UI 文本用 `sp`（随系统字体缩放）；提供「标准/大/特大」3 档映射 sp 倍数；棋盘数字随 `cell_dp` 自动放大；**热区恒 ≥44dp 不被字号挤压** | 美术圣经 §8.3 |
| **高对比主题** | 设置 S7（主题子项） | light/dark + 可选「高对比」强化 bevel 与数字描边 | 美术圣经 §2.3 |
| **触控热区** | —（全局） | 所有可点控件 ≥44dp；长按环形进度 + 轻震动给明确「进入标记」反馈，降低误触 | 美术圣经 §8.3 |
| **屏幕阅读器** | 路线图 | 预留单元格状态播报接口（"r 行 c 列，已翻开，数字 3"），本期不实现 | 美术圣经 §8.5 |

> 设计原则（美术圣经）：可访问性是基础要求，非锦上添花；UX 三项开关均须在设置页一级入口可见，不得埋深。
